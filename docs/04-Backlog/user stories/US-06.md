## [US-06] - Quản lý xem Dashboard Doanh thu

As a Quản lý nhà hàng (Manager), I want theo dõi Dashboard tổng quan về doanh thu, tỷ lệ lấp đầy bàn và top món bán chạy theo thời gian thực, so that tôi đưa ra các quyết định điều phối kinh doanh kịp thời ngay trong ca làm việc.

Context:
- `FR-06` / `REQ-13`: Dashboard báo cáo Real-time (Doanh thu, Top món, Tỷ lệ lấp đầy).
- `NFR-RO-03`: Quyền hạn (RBAC) - Chỉ Role Manager mới có quyền truy cập Route/API Dashboard. Phục vụ truy cập sẽ bị văng 403 Forbidden.
- **AI Integration (Under the hood):** Tích hợp AI Detect Anomaly (Phát hiện bất thường) dưới Backend. AI sẽ phân tích log dữ liệu và bắn cảnh báo thông qua Snackbar/Toast tiêu chuẩn của UI hiện tại. Tuyệt đối không thay đổi Layout, không thêm Box Chatbot hay Component lạ.

Acceptance Criteria:

AC1 (Happy Path - Hiển thị các chỉ số lõi cực nhanh)
Given Manager đăng nhập thành công và vào tab Dashboard,
When trang load xong (thời gian dưới 2 giây),
Then UI hiện tại hiển thị rõ ràng: (1) Tổng doanh thu ca hiện tại, (2) Biểu đồ Top 5 món bán chạy nhất, (3) Tỷ lệ lấp đầy bàn (Occupancy Rate).

AC2 (Business Rule - Cập nhật Real-time Data Streaming)
Given Manager đang treo máy ở màn hình Dashboard,
When một bàn bất kỳ hoàn tất thanh toán (thuộc US-05),
Then tổng doanh thu tự động nhảy số (hiệu ứng rolling number) và biểu đồ re-render cập nhật mượt mà không cần F5 (dựa trên push event từ SSE/WebSocket Backend đẩy lên).

AC3 (Advanced Feature - AI Anomaly Detection qua UI Toast)
Given AI Engine chạy ngầm ở Backend liên tục phân tích luồng dữ liệu (Data Stream) của ca làm việc,
When AI phát hiện Tỷ lệ Hủy món (Void Rate) của ca này cao hơn 20% so với trung bình, hoặc doanh thu đột ngột giảm sâu,
Then Frontend nhận event và hiển thị một Banner/Toast cảnh báo màu đỏ (dùng component Alert mặc định của UI): "Cảnh báo hệ thống: Tỷ lệ Hủy món đang cao bất thường (Tăng 20%). Vui lòng kiểm tra Bếp/Phục vụ".

AC4 (Edge Case - Ca làm việc trắng / Chưa có dữ liệu)
Given Nhà hàng vừa mở cửa ca sáng, chưa có bàn nào order (Doanh thu = 0),
When Manager vào trang Dashboard,
Then hệ thống hiển thị Empty State tiêu chuẩn: "Chưa có dữ liệu hôm nay. Sẵn sàng đón khách!" thay vì báo lỗi chia cho 0 hay hiển thị biểu đồ rỗng méo mó.

AC5 (Fallback / Error Handling - DB Timeout / Phân quyền NFR-RO-03)
Given Lượng truy vấn quá lớn khiến Database xử lý chậm hoặc mất kết nối mạng cục bộ,
When Manager mở Dashboard,
Then hệ thống hiển thị dữ liệu từ Redis Cache của 5 phút trước kèm Toast nhỏ màu vàng: "Sự cố mạng: Dữ liệu đang hiển thị bị trễ 5 phút". Trang web tuyệt đối không bị sập (White screen).
*Lưu ý kèm theo:* Nếu tài khoản `Waiter` truy cập trái phép URL `/dashboard`, hệ thống chuyển hướng về trang chủ kèm UI Alert `403 Access Denied` (`NFR-RO-03`).

Out of Scope:
- Phân tích Text GenAI tốn diện tích màn hình hoặc thêm Chatbot nổi.
- Xuất file PDF, Excel kế toán đối soát phức tạp.

Dependencies:
- Role-based Access Control (RBAC) Middleware chặn API.
- Caching System (Redis) và SSE (Server-Sent Events) cho Real-time cập nhật.
- Backend AI Module (Anomaly Detection) chỉ trả về flag cảnh báo (True/False).

Estimate: 3 points
